Data representation

Representations are parametric in the type 'f of field values, as well as the type 'r of record memory.

type 'f field_reference = {
  1. field_ref : 'f field;
  2. field_ref_loc : Cobol_common.Srcloc.TYPES.srcloc;
}

General-purpose reference to a data field; comes with a source location.

and 'f field =
  1. | Constant_field of 'f immutable_field
  2. | Field_in_memory of {
    1. field : 'f resolved_field;
    2. field_info : 'f field_definition_info;
    }
    (*

    A field for which we can compute the location in the record.

    *)

Manipulated COBOL fields may either be constant or lie in memory.

and 'f immutable_field = 'f

We directly map immutable fields with their value representation.

and 'f field_definition_info = {
  1. field_definition : Cobol_data.Types.field_definition Cobol_common.Srcloc.TYPES.with_loc;
  2. field_initial_value : 'f immutable_field option;
}

A field in memory is addressable and may have an initial value. It always comes from a definition in a COBOL source.

and 'f resolved_field =
  1. | Fixed_field of 'f
  2. | Table_field of 'f resolved_table_cell

Resolved fields may either be fixed, or require access to already known indexing data.

and 'f resolved_table_cell = {
  1. cell_first_field : 'f resolved_field;
  2. cell_index_field : 'f field_reference;
  3. cell_index_max : int;
  4. cell_stride : int;
}
and 'r record_handle = {
  1. record_memory : 'r;
  2. record_definition : Cobol_data.Types.record;
}

Handle for record memory: associates a memory with its definition.

Module representation

In addition to the type variables above, the type of modules is parametric in the type 'm of module memory.

module FIELDS_MAP = Cobol_unit.Resolver_map
type 'f fields_map = 'f field_access FIELDS_MAP.t

Named fields are always associated with fields that lie in memory (immutable fields typically come from literals in source programs).

and 'f field_access = {
  1. access_field : 'f fixed_mutable_field;
  2. access_ranges : 'f access_range list;
}
and 'f fixed_mutable_field = {
  1. fixed_field : 'f;
  2. fixed_field_info : 'f field_definition_info;
}

A field that is at a fixed location in a record.

and 'f access_range =
  1. | Fixed_range of {
    1. max : int;
    }
  2. | Depending_range of {
    1. min : int;
    2. max : int;
    3. odo_field : 'f fixed_mutable_field;
