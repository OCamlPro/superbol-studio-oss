Module Superbol_project.Cached_diagnostics

Diagnostics of documents, cached on their own so that they can be reported for documents that are not open, without restoring their (much larger) analysis for the LSP.

Diagnostics are held as the parser and the typechecker give them, and only translated when reported.

Caching

val slot : Superbol_project__.Project_analysis.keys -> Superbol_cache.Types.key

slot keys is the slot in which the diagnostics of the document keys are recorded; it is theirs only, as they are stored at times of their own.

val store : Superbol_cache.Cache.t -> keys:Superbol_project__.Project_analysis.keys -> label:string -> t -> unit

store cache ~keys ~label diags records diags in cache, for as long as the analysis for the LSP under Project_analysis.key_for_lsp keys holds, and supersedes the diagnostics of previous versions of the document.

val lookup : Superbol_cache.Cache.t -> keys:Superbol_project__.Project_analysis.keys -> resolve:(Superbol_cache.Types.witness -> bool) -> t option

lookup cache ~keys ~resolve retrieves the diagnostics of the document keys from cache.

val mem : Superbol_cache.Cache.t -> keys:Superbol_project__.Project_analysis.keys -> bool

mem cache ~keys indicates whether cache holds diagnostics for the document keys, without checking their witnesses.

val store_for_analysis : Superbol_cache.Cache.t -> keys:Superbol_project__.Project_analysis.keys -> label:string -> ?fresh:bool -> Superbol_project__.Project_analysis.for_lsp -> unit

store_for_analysis cache ~keys ~label ?fresh analysis stores the diagnostics of analysis in cache, unless it already holds some for the document. fresh (defaults to false) indicates analysis was just computed, so that cache need not be checked.
