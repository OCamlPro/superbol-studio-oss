Module Superbol_project.Walk

val source_files : platform:Cobol_common.Platform.TYPES.platform -> layout:Superbol_project__.Project.TYPES.layout -> Superbol_project__.Project.TYPES.project -> string list

source_files ~platform ~layout project lists the files under the root directory of project that platform deems source files, or that have an extension the project configuration assigns a source format to.

Skipped are: hidden files and directories, the work directory of the project according to layout (see Project.work_dirname), directories the project configuration excludes (see Project_config.excludes_dir), and symbolic links to directories.
