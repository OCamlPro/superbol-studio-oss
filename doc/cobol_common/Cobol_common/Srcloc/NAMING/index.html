Module Srcloc.NAMING

val register_given_filename : filename:string -> given_filename:string -> unit

Associates an internal filename (typically, absolute) with a given filename (e.g, relative). The given name is then used in place of the internal one when printing locations in pp_srcloc, and returned by start_filename or given_filename.

val given_filename : string -> string

given_filename filename returns the given filename that was last associated with filename, if any. Otherwise, returns filename.
