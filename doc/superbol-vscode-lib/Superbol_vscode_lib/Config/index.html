Encoding of COBOL files

val string_in : WS_CONF.t -> key:string -> string option
val cobol_files_encoding : scope:Vscode.ConfigurationScope.t -> string option

cobol_files_encoding ~scope is the encoding VS Code opens COBOL files in scope with: files.encoding, unless the [cobol] section overrides it. The LSP server follows the same rule (see `file_encoding_in_client_config' in `cobol_lsp/lsp_server.ml').

val guesses_encoding : scope:Vscode.ConfigurationScope.t -> bool

Whether VS Code guesses the encoding of files in scope (in which case the encoding of COBOL files may differ from cobol_files_encoding).
