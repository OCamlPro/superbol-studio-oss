Module Superbol_platform.Heuristics

val autodetect_format : source_contents:string -> filename:'a -> Cobol_common.Platform.TYPES.source_format_id
val source_extensions : string list

Filename extensions of files that may hold COBOL programs, compared regardless of case. None is a copybook-only extension (see Cobol_common.Copybook.copybookonly_extensions).

val is_source_file : filename:string -> bool
val is_hidden_file : filename:string -> bool

Files and directories whose name starts with a dot are hidden, as is customary on Unix-like systems and for many tools on Windows (e.g. .git or .vscode). The hidden attribute of Windows file systems is ignored.
