val analyze_file : Common_args.t -> string -> ANALYSIS.t analyzed_file

analyze_file common filename analyzes filename according to the configuration of its project and the overrides in common, reusing or else filling the project's cache.

val analyze_file_for_lsp : Common_args.t -> string -> ANALYSIS.for_lsp analyzed_file

analyze_file_for_lsp common filename is like analyze_file, except that it provides an analysis for the LSP. Use this to get all artifacts the LSP would need, or to fill the cache for the LSP.

derived_entry ~label ~inputs located is the cache, and key of the derived entry, for located, along with the keys of the analysis it may derive from.

val analyze_located_n_witness : Common_args.t -> cache:Superbol_cache.Cache.t -> keys:ANALYSIS.keys -> located_file -> ANALYSIS.t analyzed_file * Superbol_cache.Types.key

analyze_located_n_witness common ~cache ~keys located is the analysis of located, along with the key of the cache entry it is held in: the analysis for the LSP if cache holds one, or else the (normal) analysis, computed and stored on a miss.

val derive_located : Common_args.t -> label:string -> inputs:Superbol_cache.Types.digest list -> derive:(ANALYSIS.t analyzed_file -> 'a) -> located_file -> 'a * bool * ANALYSIS.t analyzed_file Stdlib.Lazy.t
val derive_from_file : Common_args.t -> label:string -> inputs:Superbol_cache.Types.digest list -> derive:(ANALYSIS.t analyzed_file -> 'a) -> string -> 'a * bool

derive_from_file common ~label ~inputs ~derive filename is derive applied to the result of analyze_file on filename. The result is cached in the project's cache, along with the analysis it is derived from (which may be one for the LSP if the cache holds it): a hit on the derived value requires the analysis itself to be a hit, and does not entail retrieving the latter.

label identifies the derivation, and inputs should hold digests of everything derive depends upon besides the analysis result. The Boolean indicates a hit.

Note that derive must return a value that holds no closure, and be fully determined by the producer (as identified by the cache), the analysis, and inputs.

val derive_n_analyze_file : Common_args.t -> label:string -> inputs:Superbol_cache.Types.digest list -> derive:(ANALYSIS.t analyzed_file -> 'a) -> string -> 'a * bool * ANALYSIS.t analyzed_file

derive_n_analyze_file common ~label ~inputs ~derive filename is like derive_from_file, except that it also returns the analysis of filename, which is retrieved from the project's cache in case of a hit on the derived value. Use this to only cache, as derived value, what can not be obtained from the analysis directly.

val lookup_located : Common_args.t -> label:string -> inputs:Superbol_cache.Types.digest list -> located_file -> ('a * ANALYSIS.t analyzed_file Stdlib.Lazy.t) option
val lookup_derived : Common_args.t -> label:string -> inputs:Superbol_cache.Types.digest list -> string -> 'a option

lookup_derived common ~label ~inputs filename retrieves a value previously recorded by derive_from_file with the same label and inputs, without analyzing filename; None on a miss.

val lookup_derived_n_analysis : Common_args.t -> label:string -> inputs:Superbol_cache.Types.digest list -> string -> ('a * ANALYSIS.t analyzed_file) option

lookup_derived_n_analysis common ~label ~inputs filename is like lookup_derived, except that it also returns the analysis of filename in case of a hit, which is retrieved from the project's cache (it is computed and stored anew if the cache no longer holds it).

val report : Common_args.t -> ppf:Stdlib.Format.formatter -> ANALYSIS.t analyzed_file -> unit

report common ~ppf analysis reports analysis diagnostics on ppf.

val analyze_n_report : Common_args.t -> for_lsp:bool -> ppf:Stdlib.Format.formatter -> string list -> unit

analyze_n_report common ~for_lsp ~ppf files analyzes files in turn, and reports diagnostics on ppf. Files are analyzed with analyze_file_for_lsp if for_lsp holds (so the cache is filled for the LSP), or else with analyze_file.

val with_analysis_results : Common_args.t -> f:(ANALYSIS.t analyzed_file -> unit) -> ppf:Stdlib.Format.formatter -> string list -> unit

with_analysis_results common ~f ~ppf files analyzes files with analyze_file, in turn, reports analysis diagnostics on ppf, and then passes the analysis result to f.

val with_typeck_outputs : f:(ANALYSIS.t analyzed_file -> Cobol_typeck.Outputs.t -> unit) -> Common_args.t -> ppf:Stdlib.Format.formatter -> string list -> unit

with_typeck_outputs common ~f ~ppf files acts like with_analysis_results, except f is given the type-checking result as second argument. Therefore f is only called if the type-checking succeeds.
