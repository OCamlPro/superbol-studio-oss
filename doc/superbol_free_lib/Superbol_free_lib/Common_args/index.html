Progress

val progress_arg : unit -> (unit -> progress_display) * Ezcmd.V2.EZCMD.TYPES.arg_list

progress_arg () is the --progress option (alone in its list), along with a function that tells how to display progress accordingly (by default, it is shown when stderr is a TTY).

val pretty_progress : progress_display -> 'a Pretty.proc

pretty_progress display reports progress as display tells.

val clear_progress : unit -> unit

clear_progress () erases the progress message shown on stderr, if any, so that what is printed next does not mix with it.
