Module Superbol_free_lib.Command_parallel

Running any sub-command on batches of files, in parallel processes.

val name : string
val split_at_separator : string list -> string list * string list option
val read_lines : Stdlib.in_channel -> string list
val names_subcommand : subcommands:Ezcmd.V2.EZCMD.TYPES.sub list -> string list -> bool
val make : subcommands:Ezcmd.V2.EZCMD.TYPES.sub list -> run_in_process:(string list -> unit) -> Ezcmd.V2.EZCMD.TYPES.sub

make ~subcommands ~run_in_process is the sub-command, that runs any of subcommands; run_in_process args runs this program with the arguments args (that do not include the name of the program) within the current process, and may not return.
