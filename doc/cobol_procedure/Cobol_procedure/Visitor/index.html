Module Cobol_procedure.Visitor

Folding visitor for the typed procedure tree.

Methods for the terms that are shared with the parse tree (names, literals, procedure names...) are inherited from Cobol_ptree.Terms_visitor.shared_folder. Other methods have the same name as in the parse tree visitors.

Ill-typed statements are leaves: their parse tree is never visited.
